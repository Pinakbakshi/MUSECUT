# MUSECUT code index

- app/page.tsx — responsive creator workspace, local video selection, lyrics, worker request and ZIP download.
- app/layout.tsx — application metadata and root layout.
- app/globals.css — dark visual system and Tailwind layers.
- backend/app/main.py — FastAPI upload endpoint, SRT/LRC parsing, lyric-window selection and FFmpeg rendering.
- backend/requirements.txt — Python worker dependencies.
- backend/Dockerfile — FFmpeg-enabled worker container.
- README.md — setup, API contract, limits and roadmap.
